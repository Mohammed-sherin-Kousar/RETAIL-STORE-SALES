# Retail Store Sales Analysis

##  Project Overview

Developed a **Retail Store Sales Analysis project using Excel** to analyze customer transactions, sales performance, product categories, payment methods, and customer spending patterns. The project uses data cleaning, analysis, formulas, and visualizations to generate meaningful business insights.

##  Objective

* Analyze retail sales and customer transaction data.
* Understand purchasing and spending patterns.
* Analyze sales across product categories and locations.
* Identify top-performing customers and products.
* Generate business insights using Excel-based analysis.

##  Technologies Used

* Microsoft Excel
* Excel Formulas
* Pivot Tables
* Data Analysis
* Data Visualization

##  Key Steps

* Imported and explored the retail sales dataset.
* Reviewed transaction and customer-level information.
* Performed data cleaning and preparation.
* Analyzed sales, quantity, and customer spending.
* Used Excel formulas for calculations and analysis.
* Created Pivot Tables for summarizing sales data.
* Created charts and visualizations to present key findings.
* Identified important customer and sales patterns.

##  Analysis Performed

* Total Sales / Total Spent
* Average Transaction Value
* Customer-wise Spending
* Product Category Analysis
* Quantity Analysis
* Payment Method Analysis
* Location-wise Sales
* Top Customers
* Sales Trends and Distribution

##  Result

* Successfully transformed retail transaction data into an organized analytical workbook.
* Identified customer spending and purchasing patterns.
* Analyzed sales performance across different categories and locations.
* Identified high-value customers based on total spending.
* Created summarized views and visualizations for easier business analysis.
